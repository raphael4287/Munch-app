# Munch — 美食交友滑卡神器

**像交友軟體一樣滑餐廳**  
在全台灣、全世界發現好吃的餐廳

![Munch Prototype](https://images.unsplash.com/photo-1569718212165-3a8278d5f624?w=800&q=80)

## ✨ 什麼是 Munch？

Munch 是一款**美食交友型**餐廳發現應用程式。

你可以用 **Tinder 般的左右滑動** 快速瀏覽餐廳：
- **右滑 ❤️** → 喜歡這家店（收藏）
- **左滑 ❌** → 不感興趣（跳過）
- **向上滑** → 立刻出發！（GO 導航）

這不再只是找餐廳，而是**用交友的心態探索美食**。

## 🎯 核心特色

- **滑卡式互動介面**（左右滑 + 向上滑）
- **即時物理拖曳與動畫反饋**
- **真實店家卡片**（照片 + 距離 + 評分 + 特色）
- **GO 快速導航**（模擬開啟 Google Maps）
- **收藏提示與收藏紀錄**
- **使用 8 次後自動彈出使用者回饋**
- **逼真 iOS 裝置外框**（Liquid Glass 風格）
- **完全本地運行**，無需後端

## 🚀 如何使用（快速開始）

### 方法一：直接執行（最簡單）

1. 下載以下三個檔案到同一個資料夾：
   - `Munch Prototype.html`
   - `app.jsx`
   - `ios-frame.jsx`

2. 雙擊開啟 **`Munch Prototype.html`**

3. 第一次會看到歡迎畫面，點擊「開始」即可開始滑卡！

### 方法二：開發模式修改

你可以直接修改 `app.jsx` 中的店家資料，擴充更多城市與店家。

## 📍 目前狀態

**Demo 版本** 目前採用**固定店家資料**（公館、師大、台大周邊 12 家真實店家），因為尚未接入定位功能。

**未來完整版** 將支援：
- 即時 GPS 定位
- 全台灣與全球餐廳資料
- 根據你的位置推薦附近美食
- 更多城市（台北、台中、高雄、東京、紐約...）

## 📱 操作方式

| 操作              | 功能說明                  |
|-------------------|---------------------------|
| 左右滑動          | 選擇喜歡 / 跳過           |
| 點擊愛心按鈕      | 右滑收藏                  |
| 點擊 X 按鈕       | 左滑跳過                  |
| 向上滑動卡片      | 快速「GO」導航            |
| 點擊中央 GO 大按鈕 | 確認前往該店              |
| Logo 連點 5 次    | 開啟管理員回饋面板        |
